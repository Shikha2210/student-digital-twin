The question

Most student analytics asks how a student compares to everyone else.

That question has a blind spot, and it is a large one.

Same student, same week, two questions. Against the cohort they are unremarkable. Against their own normal they are among the furthest below it. A cohort-relative system sees nothing worth flagging.

Personal baseline

Twelve logins is an ordinary week for one student and a collapse for another.

Every student gets a fitted baseline — θ — estimated by shrinking their own history toward their cohort by an amount the data decides rather than a constant we choose. New students look like their cohort; well-observed students look like themselves.

Read those two carefully. The student on the right sits lower in absolute terms — yet they are at their own normal. The student on the left scores higher and is roughly a full unit below theirs. Context changes meaning, and only one of these two warrants a conversation.

Time

The twin remembers.

Each week the model does two things, always in this order. It predicts — pushing last week's state forward, drifting toward the student's baseline, widening its uncertainty because time has passed. Then it updates — folding in what actually happened, and narrowing again. Last week's answer becomes this week's starting point.

That loop is not a metaphor. It is verified: updating recursively from the previous state gives results identical to replaying every week from scratch, to 0.00e+00. The state is a sufficient statistic for the student's history.

observations→ predict→ update→ state→ risk readout→ simulated futures

Simulation

Because the state is generative, it can be run forward.

Six hundred particles are drawn from the student's current posterior and pushed eight weeks into the future. What comes back is a distribution over paths, not a single confident line.

Observed trajectory, then simulated futures

Solid is observed. Everything past the boundary is model-generated.

Model-generated scenario — not a causal estimate. The dataset records no interventions, so the sensitivity is assumed, not fitted. This shows what the model's dynamics imply, never what an action would achieve for a real student.

Definition

A digital twin is a claim, not a name.

Ours is defined by four properties we can fail — and two of the four tests have not been written yet, which we say here rather than in a footnote.

01

Personalised

Set-point recovery r = 0.94 against known ground truth

Learns each student's own baseline and how quickly they return to it after a setback. The reversion rate is a fitted parameter, not a hand-built feature.

02

Continuous

Test T1 PASS — recursive equals full replay, exactly

Updates each week as new observations arrive, carrying the entire history inside two numbers and their uncertainty. Not real-time: the data is weekly and historical.

03

Generative

Test T2 PASS — 90% band covers 89.6% of held-out observations

Simulates many possible futures with honest spread. An earlier version failed this test with bands four times too wide; we found the cause and fixed it rather than moving the threshold.

04

Intervenable

Test T3 NOT IMPLEMENTED

Accepts a hypothetical action as a model input, structurally separate from any observation. The mechanism works; its stability across refits has not yet been tested.

Scientific restraint

The limitations are part of the product.

An instrument that hides its failures is not an instrument. These appear inside the application itself, beside the charts they qualify — not only in a paper:

  • Nothing has run on real student data. Every figure on this site comes from a synthetic cohort with known ground truth. The OULAD dataset is prepared but has not been processed.
  • Interventions are not causal estimates. No interventions are recorded anywhere in the data, so the sensitivity is assumed. Scenarios say what the model implies, never what an action would do.
  • Uncertainty is currently under-stated. Nominal 95% intervals cover about 81% of true states. The interface says so beside the chart rather than quietly widening the band.
  • Two capability tests are unwritten, so the latent dimensions are labels of convenience rather than validated constructs.
  • A simpler model sometimes wins. Where risk is driven by fast week-to-week change, plain logistic regression on hand-built features outperforms the twin — and we publish that number alongside our own.
